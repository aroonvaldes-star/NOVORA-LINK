# NOVORA-LINK 1.4 / AppControl 1.4.66 — EXPERIMENTAL

Esta versión experimental reúne NOVORA para Windows x64 y la APK AppControl 1.4.66 en **un solo instalador**. Incluye el runtime de .NET 8 para Windows, ADB, scrcpy, LinkEngine Relay, los avisos legales y las fuentes redistribuibles de FFmpeg y libusb. La APK se instala en Android desde la opción **COMPROBAR APP** de NOVORA; ejecutar el instalador de Windows no instala automáticamente la aplicación en el teléfono.

## Precauciones

- **Es una versión experimental.** No se ha confirmado de extremo a extremo una sesión PC–Android con tráfico real de LinkEngine, cuadros de VisionEngine y salida de ExInEngine para este paquete.
- El instalador de Windows **no tiene firma Authenticode** y requiere permisos de administrador. Windows puede mostrar una advertencia antes de ejecutarlo.
- La APK 1.4.66 puede tener una firma distinta de la aplicación que ya esté instalada en tu teléfono. Android rechazará la actualización directa si las firmas no coinciden. Desinstalar la versión anterior elimina sus datos internos; hazlo solo si aceptas esa pérdida. NOVORA no desinstala la aplicación automáticamente.
- La APK de Release incluida está dirigida a dispositivos Android ARM64. No se ha verificado este paquete en todos los teléfonos, controladores, GPU ni configuraciones de red.
- El binario se generó desde un checkout local con cambios todavía sin integrar en Git. El código fuente asociado al tag del pre-release no reproduce por sí solo este instalador. Usa las huellas anteriores para identificar exactamente los archivos descargados.

Conserva esta versión para pruebas. Si encuentras un problema, anota la versión de Windows y Android, el modelo del dispositivo, el tipo de conexión (USB o LAN) y los pasos para reproducirlo.
