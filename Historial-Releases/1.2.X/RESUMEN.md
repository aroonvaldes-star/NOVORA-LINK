# NOVORA 1.2 — resumen recuperado

Base reorganizada para Visual Studio y VS Code.

Estructura documentada:
- `DEBUG/`
- `RELEASE/`
- `VS/NOVORA/`
- `VSCODE/NOVORA/`
- `docs/`

La interfaz usa Mbps como unidad. Un valor legado de `5 MB/s` se convierte a `40M`.
Incluye modo de prueba para normalización, simulación de conexión y flujo visual de recovery.
