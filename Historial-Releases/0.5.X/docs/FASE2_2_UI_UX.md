# Fase 2.2 — UI/UX y controles

Los botones inferiores usan menús contextuales, pero estos deben abrirse con clic izquierdo para ser accesibles desde la interfaz.

- Configuración: abre ventana de ajustes.
- Iniciar NOVORA: prepara y lanza la sesión.
- Configuraciones rápidas: abre menú con Optimizar sistema y Limpiar caché.
- Otras acciones: abre menú con Respaldo y Actualización.
