## Español

NOVORA-LINK reconoce y agradece el trabajo de los proyectos open source y comunidades técnicas que han servido como referencia, dependencia o base de aprendizaje para el proyecto.

### scrcpy

**Genymobile / Romain Vimont (rom1v)** — herramienta para visualizar y controlar dispositivos Android.

scrcpy se distribuye bajo Apache License 2.0. Su trabajo ha servido como referencia técnica importante para la arquitectura de pantalla, video, audio y control que NOVORA desarrolla en VisionEngine.

Proyecto oficial: https://github.com/Genymobile/scrcpy

### Gnirehtet

**Genymobile** — herramienta de reverse tethering para Android mediante ADB.

Gnirehtet se distribuye bajo Apache License 2.0. Su arquitectura ha servido como referencia técnica para el desarrollo de LinkEngine.

Proyecto oficial: https://github.com/Genymobile/gnirehtet

### Android Debug Bridge (ADB)

**Android Open Source Project (AOSP)** — infraestructura Android Debug Bridge.

ADB continúa siendo una pieza intencional de la arquitectura de NOVORA-LINK para descubrimiento, autorización, provisioning, bootstrap, diagnóstico y recuperación.

Fuente: https://android.googlesource.com/platform/packages/modules/adb/

## English

NOVORA-LINK acknowledges and thanks the open-source projects and technical communities that have served as references, dependencies or learning foundations for the project.

### scrcpy

**Genymobile / Romain Vimont (rom1v)** — Android display and control software.

scrcpy is distributed under Apache License 2.0. Its engineering has been an important technical reference for the screen, video, audio and control architecture NOVORA is developing in VisionEngine.

Official project: https://github.com/Genymobile/scrcpy

### Gnirehtet

**Genymobile** — Android reverse tethering over ADB.

Gnirehtet is distributed under Apache License 2.0. Its architecture has served as a technical reference for LinkEngine development.

Official project: https://github.com/Genymobile/gnirehtet

### Android Debug Bridge (ADB)

**Android Open Source Project (AOSP)** — Android Debug Bridge infrastructure.

ADB remains an intentional part of NOVORA-LINK for discovery, authorization, provisioning, bootstrap, diagnostics and recovery.

Source: https://android.googlesource.com/platform/packages/modules/adb/
